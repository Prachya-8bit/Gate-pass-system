# Gate Pass → epro Sync (สคริปต์กรอกข้อมูลอัตโนมัติ)

สคริปต์นี้ทำงานแทนคน: log-in เข้า `eprocurement.syssteel.com` ด้วยบัญชีของคุณ อ่านรายการลงทะเบียนคนงานจากระบบ Gate Pass แล้วกรอกลงฟอร์ม `reg/index.aspx` ทีละรายการ รายการที่ส่งแล้วจะถูกจดไว้ใน `state/submitted.json` — รันซ้ำกี่ครั้งก็ไม่กรอกซ้ำ

> ⚠️ ทุกรายการที่สคริปต์กรอก ระบบ epro จะบันทึกในชื่อบัญชีของคุณ ตรวจ dry-run ให้มั่นใจก่อนรันจริงเสมอ

## ติดตั้งครั้งแรก

```bash
cd automation
npm install
npx playwright install chromium
cp .env.example .env        # แล้วเปิดแก้ กรอก username/password ของ epro
```

## ก่อนรันได้จริง ต้องทำ 1 อย่าง

Selector ของฟอร์ม `FrmWorker.aspx` ใส่ครบแล้ว (จากไฟล์ใน `pages/`) เหลือเฉพาะ**หน้า login จริง** — เปิดหน้าที่มีช่องกรอก username/password → `Ctrl+S` เซฟเป็น `pages/login-real.html` → ให้ Claude เติม 3 selector สุดท้ายใน `selectors.mjs` (สคริปต์จะไม่ยอมรันจนกว่าจะครบ)

การจับคู่ข้อมูล: record ที่บริษัท + ช่วงวันที่ + โซนเดียวกัน จะถูกรวมเป็น**ใบงานเดียว**ใน epro แล้วเพิ่มคนงานทีละคนด้วยปุ่ม "เพิ่ม" ของฟอร์ม ค่าที่ต้องเลือกเอง (Plant, ผู้อนุมัติ, เบอร์ผู้ขอ) ตั้งใน `.env`

## การใช้งาน

```bash
# 1) เปิด Gate Pass dev server ทิ้งไว้ (อีก terminal หนึ่ง ที่โฟลเดอร์หลัก)
npm run dev

# 2) ทดสอบแบบไม่กด submit — กรอกรายการแรกให้ดูเฉย ๆ
npm run sync:dry

# 3) รันจริง
npm run sync
```

- Browser จะเปิดขึ้นมาให้เห็นทุกขั้นตอน (ไม่ใช่เบื้องหลัง) — ดูมันทำงานได้เลย
- ถ้าพังกลางทาง สคริปต์หยุดทันที + เซฟภาพหน้าจอไว้ที่ `screenshots/` และรายการที่ส่งไปแล้วไม่ถูกส่งซ้ำเมื่อรันใหม่
- อยากให้รันเองทุกวัน: ตั้ง Windows Task Scheduler เรียก `npm run sync` (แนะนำให้รันเองช่วงแรกจนมั่นใจก่อน)

## ข้อจำกัดที่รู้ไว้

- ถ้า epro เปลี่ยนหน้าเว็บ ต้องอัปเดต `selectors.mjs` ตาม
- ถ้าหน้า login มี CAPTCHA/OTP สคริปต์จะผ่านไม่ได้ — ต้องคุยทางอื่น
- ต้องรันจากเครื่องที่เข้าถึง epro ได้ (ในเครือข่ายบริษัท/VPN)
